Les topologies réseau

La topologie décrit la façon dont les appareils sont reliés entre eux. Les traits animés représentent la circulation des données.

Les périphériques réseau

Chaque appareil a un rôle précis. Achemine : choisit une route entre réseaux. Commute : oriente les trames dans un même réseau. Transmet : envoie ou répète le signal. Filtre : contrôle le trafic.
